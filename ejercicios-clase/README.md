## Entorno virtual

Para crear el entorno virtual en la raíz del repositorio se usó:

python -m venv venv

Para activarlo (en CMD):

venv\Scripts\activate

Antes de instalar cualquier dependencia, se verificó que la terminal mostrara
el prefijo `(venv)`, confirmando que el entorno estaba activo:

(venv) C:\Users\57313\Documents\2026-2\curso-analisis-algoritmos>

Con el entorno activado, se instaló matplotlib:

pip install matplotlib
